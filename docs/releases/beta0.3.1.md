# 同传翻译 beta0.3.1

Windows x64 Beta 预发布版，应用版本为 0.3.1。本版修复上一版中会话记录看不到新翻译句子的问题，并让字幕记录在窗口重载后仍然保留。不同会议软件及音频设备组合尚未完成全面人工验收，因此继续作为预发布版提供。

## 更新内容

- 修复新一轮同传开始后，会话记录里看不到新句子的错误。字幕序号只在一个同传会话内有效，旧版本却按它排序，导致新句子被插到上一轮记录中间、实时翻译面板也一直停在上一轮的最后一句。现在改为按生成时间排序，实时面板只取当前会话的字幕。
- 修复观看位置错乱：按时间排序后，最新句子始终显示在会话记录最上方，实时翻译的原文/译文与正在识别的进度保持同一轮会话。
- 会话记录改为本地保存：窗口重载或应用重启后，最近的字幕记录会恢复显示；点垃圾桶清空记录时，同时清除本地保存的副本。记录仍只保留最近 40 条，且不写入任何云端或账号。
- 修复停止同传瞬间丢掉最后一句：翻译引擎在会话停止过程中仍会送达最后一条原文与译文，源句未能写入时译文会退回待配对队列而不是被丢弃。

## 安装与升级

下载 `simultaneous-translator_0.3.1_x64-setup.exe` 安装。升级前请停止同传并退出旧版应用；同页提供 `SHA256SUMS.txt` 供核对安装包。

- 默认的隔离系统声音采集要求 Windows build 20348 及以上版本，建议使用 Windows 11 x64。
- 在“设置 → 同传模型”配置当前接口对应的 API Key。密钥仍通过 Windows 凭据管理器保存。
- 从 0.3.0 升级会保留原有设置、语言与设备选择，无需重新配置；已保存的字幕记录从本版开始才会写入本地。
- 向通话软件发送译音时，在本软件中连接译文输出，并在通话软件中将麦克风选为 `CABLE Output (VB-Audio Virtual Cable)`。本软件不修改其他应用的设备选择。
- VB-CABLE 为独立的第三方可选组件，不包含在本安装包中；安装由其官方程序完成，可能需要管理员确认和重启。相关声明与许可入口保留在软件中。

## 验证范围

已通过前端生产构建（tsc + vite）、81 项 Python 引擎检查、29 项 Rust 后端检查、4 项语言能力检查及 5 项虚拟麦克风路由检查；官方驱动下载测试默认跳过，不在发布检查中安装驱动。

本版改动集中在字幕记录的排序、当前句判定与本地保存，以及停止过程中的最后一条字幕。真实跨应用通话、不同硬件和完整安装升级流程仍需进一步人工验证。
