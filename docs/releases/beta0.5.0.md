# 同传翻译 beta0.5.0

Windows x64 Beta 预发布版，应用版本为 0.5.0。本版把桌面界面整体改为像素风：主界面、设置对话框与字幕悬浮窗共用同一套「2px 边框 + 1px 分割线 + 硬阴影」的像素语言，并内置 Fusion Pixel 12px 字体提供中文与拉丁字形。这是外观与可访问性层面的改版——翻译引擎、音频链路、运行时会话协议与设置结构均未改动。

## 更新内容

- 全部图标改为自绘像素图标（`desktop/src/PixelIcons.tsx`）：主界面、设置、字幕悬浮窗、虚拟麦克风与音频设备测试向导不再引用 `lucide-react`。
- 新增 `desktop/src/pixel-theme.css` 覆盖层，作用域限定在 `.app-shell--pixel`；字幕悬浮窗保留自己的窗口样式，只继承像素字体与直角边框，避免跨窗口视觉回归。
- 内置 Fusion Pixel 12px 比例中文字体（TakWolf，SIL OFL 1.1），随应用本地加载；界面不发起任何远程字体请求，许可全文随包提供，`THIRD_PARTY_NOTICES.md` 已补充署名。
- 重新生成应用图标全套尺寸（Windows / macOS / iOS / Android 资源），`icons/icon.ico` 同时用于窗口、NSIS 安装器与卸载器；WebView 侧新增 favicon 与 apple-touch-icon。
- 主界面重排：翻译区改为可聚焦、可键盘滚动的滚动框；环境区由波形可视化改为像素掌机插画；会话反馈与操作提示合并到同一区域，并新增等待态陪伴精灵与历史区装饰。
- 可访问性补充：设置导航项与设置面板补充 `aria-label`，状态卡片取值补充 `title`（长文本截断后可悬停查看），提示元素补充用于样式的状态属性。
- 动画由关键帧改为 `@starting-style` 过渡；在「减少动态效果」偏好下，字幕悬浮窗的过渡与动画同样会被冻结。
- 设置 schema 保持第 9 版：本版没有新增或改动设置项，升级不需要配置迁移。

## 安装与升级

下载 `simultaneous-translator_0.5.0_x64-setup.exe` 安装。升级前请停止同传并退出旧版应用；同页提供 `SHA256SUMS.txt` 供核对安装包。

- 从 0.4.2 或更早版本升级会保留原有设置、语言、设备选择与已保存的字幕记录，无需重新配置。
- 安装包未做代码签名，Windows SmartScreen 可能提示「未知发布者」。请先用同页 `SHA256SUMS.txt` 核对文件再运行。
- 其余环境要求不变：Windows 11 x64（进程级系统声音采集要求 Windows build 20348 及以上）、WebView2 运行时。

## 验证范围

已通过前端生产构建（tsc + vite）、Rust 后端测试 53 项（另 1 项按设计跳过）、Python 引擎与通道契约测试 150 项（86 + 18 + 36 + 10）、真实 sidecar 进程集成测试 96 项（PASS 96 / FAIL 0 / BLOCKED 0）、前端用例 45 项（音频路由 5、设备测试 5、语言能力 4、运行时状态 22、字幕窗口 9）。

本版新增一项独立的浏览器自动化检查 `_pixel-reskin-ui-check.cjs`，在 Edge 中加载开发构建后断言：像素主题类与 CSS 变量确实生效、Fusion Pixel 字体从本地 `fonts/` 目录加载且无跨域字体请求、页面内 4 张装饰与插画图片全部解码成功、主界面与设置面板在 1120×760 下均无横向溢出、且全程零 console 错误与零失败请求。

**尚未人工验收**：真实 Windows 桌面上的像素主题观感（含高 DPI 缩放与高对比度模式）、托盘图标在任务栏通知区域的实际显示、以及新图标在资源管理器与「应用和功能」中的呈现，仍需人工确认。托盘菜单、全局快捷键与悬浮窗置顶等交互的验收状态沿用 beta0.4.1 的说明，本版未有变化。
