# 同传翻译 beta0.4.0

Windows x64 Beta 预发布版，应用版本为 0.4.0。本版新增系统托盘、全局快捷键、字幕悬浮窗和运行时通道控制，同传过程中不必再切回主窗口操作。不同会议软件及音频设备组合尚未完成全面人工验收，因此继续作为预发布版提供。

## 更新内容

- 新增系统托盘：图标常驻托盘，tooltip 与菜单首项显示当前状态（未启动 / 正在连接 / 正常翻译 / 音频异常 / 网络异常），菜单可直接开始或停止同传、静音发言、开关收听与发言通道、显示或隐藏字幕悬浮窗、显示主窗口、打开设置、退出应用。关闭主窗口不再结束程序，而是收起到托盘，正在进行的翻译不中断。
- 新增 5 个全局快捷键，主窗口隐藏、最小化或失焦时同样生效：`Ctrl+Shift+Space` 开始／停止同传，`Ctrl+Shift+M` 临时静音／取消静音发言，`Ctrl+Shift+O` 显示／隐藏字幕悬浮窗，`Ctrl+Shift+L` 开关收听通道，`Ctrl+Shift+S` 开关发言通道。快捷键由主程序注册，网页层不具备注册或注销能力；某一项被其他软件占用时只影响该项，主界面会提示具体是哪一项注册失败。
- 新增字幕悬浮窗：无边框、半透明、跨应用置顶、不占任务栏，可拖动可缩放，只显示当前原文与译文、最近 3 条字幕和错误提示，字号跟随设置中的“字幕大小”。窗口按需创建并复用同一实例，反复开关不会产生第二个窗口；隐藏或关闭悬浮窗、把主窗口收起到托盘，都不会中断正在进行的同传。
- 新增运行时通道控制：同传进行中可直接静音发言、临时关闭或重新打开收听／发言通道，无需停止会话。这些开关只作用于当前会话，不写回设置文件；重新开始同传后恢复为设置里的通道配置。关闭发言通道会同时解除静音，避免出现“通道已关却仍然静音、重新打开后没有声音”的失效状态。
- 托盘、快捷键与主界面按钮统一走同一个 native 动作分发器，三者状态一致；正在启动或停止时重复触发不会创建第二个会话，250ms 内的重复按键会被忽略。
- 修复 `cargo test` 在本机无法启动的问题：托盘功能启用后，Common-Controls v6 清单原先只链接到 bin 目标，库的单元测试 harness 绑到了 `comctl32` v5，加载即失败（`STATUS_ENTRYPOINT_NOT_FOUND`）。构建脚本现在把资源保留在搜索路径，仅由测试 harness 额外链接，Rust 测试恢复正常运行。
- 依赖约束：`tauri-plugin-global-shortcut` 锁定 `~2.3.2`。2.4.0 会把 `tauri` 抬到 2.12，与 npm 侧 `@tauri-apps/api` 2.11 失配，`tauri build` 会直接以“Found version mismatched Tauri packages”拒绝构建。

## 安装与升级

下载 `simultaneous-translator_0.4.0_x64-setup.exe` 安装。升级前请停止同传并退出旧版应用；同页提供 `SHA256SUMS.txt` 供核对安装包。

- 从 0.3.x 升级会保留原有设置、语言、设备选择与已保存的字幕记录，无需重新配置。
- 托盘与快捷键无需额外权限或注册表改动；退出应用前会先注销快捷键并结束本地引擎。
- 安装包未做代码签名，Windows SmartScreen 可能提示“未知发布者”。请先用同页 `SHA256SUMS.txt` 核对文件再运行。
- 其余环境要求不变：Windows 11 x64（进程级系统声音采集要求 Windows build 20348 及以上）、WebView2 运行时。

## 验证范围

已通过前端生产构建（tsc + vite）、Python 引擎与通道契约测试 140 项（86 + 18 + 36）、真实 sidecar 进程集成测试 96 项、Rust 后端测试 48 项（另 1 项按设计跳过）、前端用例 38 项（音频路由 5、语言能力 4、运行时状态 22、字幕窗口 7），以及打包 sidecar 冒烟。

`docs/tray-shortcuts-contract.md`、`docs/subtitle-window.md`、`docs/runtime-channel-control.md` 记录了本次三个子系统的接口契约、动作前置条件与失败口径。托盘菜单、全局快捷键在真实会议软件中的表现、悬浮窗跨应用置顶，以及不同硬件与音频设备组合仍需人工验收。
