# 同传翻译 1.0.0

正式发布 1.0 版本，帮助新用户完成 API Key 配置。

- 在 API 密钥输入框旁新增“获取密钥”超链接，打开阿里云百炼密钥控制台，并提供官方教程。
- 新用户尚未配置密钥时自动显示首次配置向导，按“获取密钥 → 填写并保存”两步完成设置。
- 向导可稍后配置，也可通过“配置同传”或“设置 → 同传模型 → 首次配置向导”重新打开。
- 密钥继续保存在 Windows 凭据管理器中；升级保留已有翻译设置和密钥。

安装包：`simultaneous-translator_1.0.0_x64-setup.exe`（Windows 11 x64）。

## 获取 API Key

1. 打开[阿里云百炼 API Key 控制台](https://bailian.console.aliyun.com/cn-beijing/model/settings/api-key)，注册或登录阿里云账号，按平台提示开通服务。
2. 选择与翻译接口一致的地域和业务空间，在 API Key 页面创建并复制密钥。
3. 返回软件，在向导中粘贴密钥并保存，再点击主界面的“开始同传”。

详细步骤见[官方密钥获取教程](https://help.aliyun.com/zh/model-studio/get-api-key)。默认链接进入华北 2（北京）；密钥需与使用的接口地域和业务空间一致。自定义接口请使用对应服务商提供的密钥。服务用量和费用以平台说明为准。

已有 0.5.2 的用户可在“设置 → 软件更新”获取本版；0.5.1 及更早版本请直接下载安装包升级。
