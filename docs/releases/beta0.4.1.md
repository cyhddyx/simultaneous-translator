# 同传翻译 beta0.4.1

Windows x64 Beta 预发布版，应用版本为 0.4.1。本版让全局快捷键可以按自己的习惯修改，并调整了托盘与字幕悬浮窗的交互细节。不同会议软件及音频设备组合尚未完成全面人工验收，因此继续作为预发布版提供。

## 更新内容

- 全局快捷键支持自定义：在“设置 → 快捷键”里可以为五个动作录制新的组合键，保存后立即生效，重启后保留。出厂默认值仍为 `Ctrl+Shift+Space`（开始／停止同传）、`Ctrl+Shift+M`（静音发言）、`Ctrl+Shift+O`（字幕悬浮窗）、`Ctrl+Shift+L`（收听通道）、`Ctrl+Shift+S`（发言通道）。
  - 组合键必须至少包含 Ctrl、Alt 或 Win 之一，且不能与其他动作重复；校验不通过的组合会给出提示并保留原值。
  - 某一项解析或注册失败只影响该项，不会让其他动作的快捷键失效；主界面仍会提示具体是哪一项注册失败。
  - 按键捕获、解析、注销与注册全部由主程序完成，网页层不获得注册或注销快捷键的能力。
- 托盘图标支持左键单击：单击显示、还原并聚焦主窗口；右键单击仍打开托盘菜单。
- 字幕悬浮窗只显示当前会话的实时句子：不再重复展示之前已经翻译完成的句子，避免悬浮窗被历史内容占满；隐藏或重新打开后同样只呈现当前会话内容。
- 设置 schema 升级到第 9 版：全局快捷键随应用设置一起保存。旧版配置会自动补入上述五个默认组合键，原有语言、设备、音色与字幕记录不受影响。

## 安装与升级

下载 `simultaneous-translator_0.4.1_x64-setup.exe` 安装。升级前请停止同传并退出旧版应用；同页提供 `SHA256SUMS.txt` 供核对安装包。

- 从 0.4.0 或更早版本升级会保留原有设置、语言、设备选择与已保存的字幕记录，无需重新配置；快捷键在首次启动时填为默认值。
- 托盘与快捷键无需额外权限或注册表改动；退出应用前会先注销快捷键并结束本地引擎。
- 安装包未做代码签名，Windows SmartScreen 可能提示“未知发布者”。请先用同页 `SHA256SUMS.txt` 核对文件再运行。
- 其余环境要求不变：Windows 11 x64（进程级系统声音采集要求 Windows build 20348 及以上）、WebView2 运行时。

## 验证范围

已通过前端生产构建（tsc + vite）、Python 引擎与通道契约测试 140 项（86 + 18 + 36）、真实 sidecar 进程集成测试 96 项、Rust 后端测试 51 项（另 1 项按设计跳过）、前端用例 40 项（音频路由 5、语言能力 4、运行时状态 22、字幕窗口 9），以及打包 sidecar 冒烟。

安装、升级与卸载路径已在 Windows 上静默验证：sidecar 字节级随包、关闭主窗口后进程仍存活（收起到托盘）、卸载无残留。

`docs/tray-shortcuts-contract.md`、`docs/subtitle-window.md`、`docs/runtime-channel-control.md` 记录了本次三个子系统的接口契约、动作前置条件与失败口径。托盘菜单与自定义快捷键在真实会议软件中的表现、悬浮窗跨应用置顶，以及不同硬件与音频设备组合仍需人工验收。
