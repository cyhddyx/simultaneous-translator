# 同传翻译 beta0.2.0

本次为 Windows x64 Beta 预发布版，应用版本为 0.2.0。新增实时双向同传，并更新为贴合窗口的浅色桌面界面。真实音频设备、外部模型及不同 Windows 环境仍需进一步验证，因此暂不作为稳定版发布。

## 更新内容

- 全新浅色左右分区界面：左侧卡通录音室麦克风动画，右侧实时识别、原文、译文及会话记录。
- 移除独立标题栏与外围留白，窗口控制融入右上角，保留拖拽与边缘缩放支持。
- 状态与语言入口移至右侧，语言按钮可打开设置；底部麦克风按钮负责同传启停。
- 设置、提示、表单及窄屏布局统一为浅色风格，支持减少动态效果偏好。
- 新增 Qwen LiveTranslate 实时引擎，可独立配置收听与发言通道、输入和播放设备、语言及音色。
- 增加实时字幕配对、通道回收、服务配置迁移及离线回归测试。
- 打包引擎加入实时 WebSocket 依赖，保留现有管线翻译模式。

## 安装与升级

下载 `simultaneous-translator_0.2.0_x64-setup.exe` 安装。升级前请停止同传并退出旧版应用。可使用同页 `SHA256SUMS.txt` 核对安装包。

旧版设置会迁移，默认仍使用管线翻译。实时同传需要在设置中切换引擎并配置独立的 DashScope API Key。双向语音建议佩戴耳机；向会议软件发送译文需要另行配置虚拟音频设备。

## 已完成验证

- TypeScript 检查和前端生产构建。
- 51 项 Python 引擎离线测试及 23 项 Rust 桌面后端测试。
- 浏览器演示：动画、会话启停、译文显示、语言设置入口、设置页切换、减少动态效果及多尺寸布局。
- 打包后的翻译引擎：独立启动、通信、Windows 音频设备枚举和正常退出。

## 验证范围

浏览器中的音频与字幕来自演示数据，不代表外部模型联调结果。真实麦克风、WASAPI 回环、双向译文播放、原生窗口拖拽缩放及安装升级流程尚未完成全面人工验收。
