# 同传翻译 1.0.2

- 新增「会话历史」：保留主界面原有“会话记录”区域与复制、清空操作，只显示最新 8 条；完整字幕记录按本机日期归档，可打开历史查看每天的全部记录，并按同传会话分组显示起止时间、通道和翻译状态。
- 新增按日期导出：“导出这一天”导出所选日期的完整记录，“导出全部”把全部日期按时间顺序写入一个 UTF-8 文本文件（带 BOM），每段会话带时间和条数标题，未完成的字幕会标注原因；桌面版弹出系统保存对话框。
- 字幕历史改存本机 WebView 的 IndexedDB，旧版本 localStorage 记录首次启动自动迁移；主界面继续保留原有复制与清空操作，同传进行中不可清空。
- 延长静默待机：客户端在长时间没有音频上行时定时发送 100 毫秒静音保活帧，避免服务端约 5 分钟空闲超时结束会话；保活不产生字幕，静音或关闭的通道同样适用。
- 回归：网络断开后仍只重连受影响通道（1.0.1 行为保持不变），保留会话、通道开关和发言静音。

安装包：`simultaneous-translator_1.0.2_x64-setup.exe`（Windows x64）。可从本页附件下载，或在应用内通过“设置 → 软件更新”检查更新。

验证：前端生产构建与 59 条 Node 用例、Rust 67 条单测、Python 引擎离线单测（`test_tauri_bridge.py` 86 条、`test_realtime_reconnect.py` 13 条）全部通过；会话历史界面与导出在浏览器模式下用 40 条跨 3 天种子数据做了自动化验证（含窄窗口布局、清空后 IndexedDB 清空与重载为空）。真实接口的长时间静默联调与系统保存对话框的交互仍需人工验收。
