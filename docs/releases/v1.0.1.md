# 同传翻译 1.0.1

- 修复网络短暂断开或服务端结束连接后，同传自动停止、必须重新点开始的问题。现在仅重连受影响通道，保留会话、通道开关和发言静音。
- 重连期间显示“正在连接”；停止会取消重连等待。鉴权、配置和音频设备故障仍给出具体错误。
- 结算中断时未完成的字幕，防止与新连接的译文配对错误。
- 修复通道快速退出时可能提前结束另一通道的竞争问题。

安装包：`simultaneous-translator_1.0.1_x64-setup.exe`（Windows x64）。可从本页附件下载，或在应用内通过“设置 → 软件更新”检查更新。
