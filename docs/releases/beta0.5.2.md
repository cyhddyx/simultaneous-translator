# 同传翻译 beta0.5.2

新增 GitHub 软件更新功能，让用户在应用内知道有新版本。

- 启动后自动检查 GitHub Releases，应用运行期间每 6 小时再次检查；支持 beta 预发布版本。
- 发现更新时在主界面提示，点击“查看更新”进入更新页面。
- 新增“设置 → 软件更新”：显示当前版本、手动检查、自动检查开关和更新说明。
- 支持下载安装包，显示下载进度，核对文件大小和 SHA-256；点击“退出并安装”打开安装向导。
- GitHub 连接失败可重试，不影响同传；同版本和旧版本不会提示升级。

安装包：`simultaneous-translator_0.5.2_x64-setup.exe`（Windows x64）。

**0.5.1 及更早版本没有自动更新检查，需要先手动下载安装本版。安装 0.5.2 后，后续新版本会在应用内提醒。**
