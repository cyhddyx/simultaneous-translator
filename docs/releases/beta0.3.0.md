# 同传翻译 beta0.3.0

Windows x64 Beta 预发布版，应用版本为 0.3.0。本版统一使用 Qwen3.8 实时同传模型，并修正双向翻译的语言、音色和播放路由。不同会议软件及音频设备组合尚未完成全面人工验收，因此继续作为预发布版提供。

## 更新内容

- 使用单一 `qwen3.8-livetranslate-flash-realtime` 模型完成识别、翻译与译音，支持语音转文字和语音转语音，移除旧的独立识别、翻译模型设置。
- 收听和发言通道独立配置：默认将对方的外语翻译为中文，将自己的中文翻译为英语；可分别选择目标语言、输出模式及播放设备。
- 音色按通道隔离：发言默认使用本人音色，收听默认使用系统音色，也可选择跟随对方的音色，避免两路共用首次采集到的声音。
- 默认系统声音采集排除本软件及翻译引擎的播放，减少译音被重复采集；指定设备回环模式会检查播放冲突。
- 设置中增加发送译文到其他应用的入口，可按需下载、校验并打开标准版 VB-CABLE 官方安装程序，再将发言译音连接到虚拟麦克风。
- 按官方能力区分 60 种文字输出语言和 29 种语音输出语言。粤语、希腊语等仅支持文字；已有不支持的语音配置会提示修正，并阻止保存或启动，不会自动替换目标语言。粤语输入仍可识别。
- 修复实时连接、语音输出和设备检测相关处理，改进错误反馈。
- 修复麦克风动画支架错位，保持底座、支撑杆和托架连续；统一语言选项、错误提示与窄窗口布局。

## 安装与升级

下载 `simultaneous-translator_0.3.0_x64-setup.exe` 安装。升级前请停止同传并退出旧版应用；同页提供 `SHA256SUMS.txt` 供核对安装包。

- 默认的隔离系统声音采集要求 Windows build 20348 及以上版本，建议使用 Windows 11 x64。
- 在“设置 → 同传模型”配置当前接口对应的 API Key。旧识别、翻译模型不再参与同传；密钥仍通过 Windows 凭据管理器保存。
- 首次升级会迁移旧设置，收听与发言的语言、音色和设备独立保存。保存设置后，重新开始同传生效。
- 向通话软件发送译音时，在本软件中连接译文输出，并在通话软件中将麦克风选为 `CABLE Output (VB-Audio Virtual Cable)`。本软件不修改其他应用的设备选择。
- VB-CABLE 为独立的第三方可选组件，不包含在本安装包中；安装由其官方程序完成，可能需要管理员确认和重启。相关声明与许可入口保留在软件中。

## 验证范围

已通过前端生产构建、81 项 Python 引擎检查、29 项 Rust 后端检查、4 项语言能力检查及 5 项虚拟麦克风路由检查；官方驱动下载测试默认跳过，不在发布检查中安装驱动。

已检查桌面和窄窗口下的语言列表、双向独立设置、不支持配置的保存及启动拦截，以及旧粤语配置的保留与修正。浏览器中的字幕和音频状态为演示数据，不代表真实模型通话。

发布安装包包含独立翻译引擎、系统采集组件和共享语言列表。发布前检查打包引擎的启动、通信、设备枚举、语言校验及退出。真实跨应用通话、不同硬件和完整安装升级流程仍需进一步人工验证。
