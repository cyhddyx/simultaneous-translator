# 同传翻译 beta0.5.1

修复连续讲话把实时字幕撑成整页、以及停止再开始后主界面实时翻译区域不再更新的问题。

- 主界面的实时原文和译文各显示末尾 3 行；字幕悬浮窗默认显示原文末尾 2 行、译文末尾 3 行。窗口高度较小时进一步减少行数，始终跟随最新内容。
- 新文字追加、字体加载、字号变化和窗口缩放后自动跟到末尾。完整的已完成原文和译文继续保存在会话记录中，可正常复制。
- 主界面与字幕悬浮窗按主程序的实际会话 ID 同步。即使停止时引擎没有发出结束事件，也能解除旧会话绑定并接收重新开启后的字幕；旧会话迟到的事件会被丢弃。

已通过前端生产构建、字幕与运行时单元测试 35 项，以及 Edge 页面检查：超过 4,000 字的原文和译文、追加文本、窗口缩放、三档字幕字号、420×120 的悬浮窗、完整记录保留；主界面和悬浮窗各连续重启 5 次，并模拟缺失结束事件与旧会话消息迟到。页面检查使用模拟的本地 IPC 事件，不发起模型请求。

安装本地生成的 `同传翻译_0.5.1_x64-setup.exe` 前，先停止同传并退出旧版应用。已有设置与凭据沿用，不需要重新配置。
